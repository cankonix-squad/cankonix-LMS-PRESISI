# Security Standards

HTTPS in deployed environments; CORS allowlist; secure headers; validation; Permission + Scope; rate limits where appropriate; secrets never committed; file type/size validation and malware scanning strategy; audit sensitive changes.

Exam: never expose correct answers during active exams; server-authoritative timer; verify authentication, enrollment, eligibility, session window and attempts; durable PostgreSQL autosave; immutable question versions. Certificate public verification exposes only approved minimal data.
