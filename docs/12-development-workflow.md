# Development Workflow

EPIC -> FEATURE -> TASK -> Codex Implementation -> Test -> REVIEW -> Architecture Review -> DONE/FIX -> Commit.

Statuses: NOT STARTED, IN PROGRESS, BLOCKED, REVIEW, DONE. Codex may set IN PROGRESS/REVIEW/BLOCKED but never DONE. DONE requires human/architecture review. Before each task Codex reads AGENTS, task, referenced docs, inspects repo, plans, implements only scope, runs checks, reports and stops.
